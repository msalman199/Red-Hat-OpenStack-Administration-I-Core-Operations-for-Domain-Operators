## 📚 Key Concepts

| Concept | Description |
|---|---|
| **Apache Camel** | An open-source integration framework for connecting and routing data between disparate systems |
| **Enterprise Integration Pattern (EIP)** | A reusable, well-defined pattern for solving common message-routing and transformation problems |
| **Java DSL** | Camel's Java-based Domain-Specific Language used to define integration routes in code |
| **Camel Route** | A defined path a message takes from a source (consumer) to a destination (producer), through processing steps |
| **Splitter** | An EIP that breaks a single message into multiple sub-messages for individual processing |
| **Aggregator** | An EIP that combines multiple related messages into a single message |
